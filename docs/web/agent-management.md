# 智能体管理页设计说明

## 卡片信息

智能体卡片仅展示低成本、可直接指导操作的信息：运行状态、活跃会话数、今日消息数、模型名称或渠道数。卡片不展示平均延迟和满意度，避免在项目概览页引入持续指标聚合、反馈采集与归因成本；性能指标后续统一归入“可观测”。

智能体名称是当前用户下不可重复的业务唯一标识，卡片不显示部署域名或额外 ID。部署访问地址只应在后续的部署详情或访问配置中展示，避免混淆项目识别与运行访问入口。

## 对话入口

卡片操作区最右侧提供“对话”按钮，使用 Lucide 图标。点击后以新标签页打开该 Agent 的前端服务地址，当前 MVP 统一指向静态占位页并携带 Agent 名称参数。占位页只提示“对话功能暂未正式上线”，不提供消息输入、会话创建或本地数据存储；当前控制台页面及其筛选状态保持不变。

## 面包屑

所有页面的“工作台”是可点击入口，始终返回总览仪表盘；最后一项代表当前页且不可点击。多层页面的中间项返回对应模块首页，例如“会话管理 / Agent 名称 / 会话标题”中的“会话管理”返回 Agent 会话概览列表。
