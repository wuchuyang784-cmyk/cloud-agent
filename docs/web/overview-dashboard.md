# 总览仪表盘设计

## 页面定位

`apps/console-mvp` 的总览仪表盘服务于单用户前端 MVP。它回答“当前使用表现如何、是否有待处理配置、下一步去哪里”，不承担单个 Agent 的状态、模型、渠道或资源详情；这些信息统一进入“智能体 Agents”页。

## 信息层级

1. 页面标题、更新时间、模型连接与创建 Agent 操作。
2. 今日、近 7 天、近 30 天分段控件；整页 KPI、趋势和调用分布随同一范围同步变化。
3. 四项 KPI：总会话数、调用量、平均响应延迟、调用成功率；对比分别为上一自然日、前 7 天、前 30 天。
4. 模型连接提醒：未配置或等待后端验证。API Key 是密码字段，不存入浏览器。
5. 调用趋势、模型调用分布、最近活动和快捷操作。

## 交互与状态

- `创建 Agent` 打开已有创建弹窗；`进入智能体` 切换到 Agent 页面；`模型连接` 打开 Agent 级配置弹窗。
- 时间范围切换只更新本地 fixture，不重置配置弹窗或导航状态。
- 模型连接提交后显示“等待后端验证”，不伪造已连接或 Runtime 已就绪。
- 每个异步数据源后续必须具备 loading、empty、error、stale 和 success 状态。

## 视觉约束

遵循 `apps/console-mvp/DESIGN.md` 和 `docs/platform-overview(优化版).html`：浅灰画布、白色面板、细边框、6px 常规圆角、紧凑信息密度。避免营销 Hero、深色大面积背景、渐变装饰、Bento 拼贴、图片素材和强滚动动效。图标统一使用 Lucide。

## 验收

- 在 1440px、1024px、390px 宽度下无横向滚动和文字遮挡。
- 时间范围会同时更新 KPI、趋势标题、横轴和模型分布数值。
- 键盘可以切换时间范围、打开/关闭模型弹窗；图标按钮有可访问名称。
- 执行 `designmd lint apps/console-mvp/DESIGN.md` 无错误或警告，并将 `css-tailwind` 导出作为 `src/styles.css` 的 token 来源。
